# Chrome Web Store listing copy

## Default listing: English

### Name

Offer Hider for Allegro

### Summary

Hide offers, products, and sellers you don't want to see on Allegro search results.

### Detailed description

Offer Hider for Allegro helps you clean up Allegro search results by hiding individual offers, whole products, or sellers you no longer want to see.

Main features:

- Hide regular and sponsored offers directly from search results.
- Hide a single offer, a product, or an available seller.
- Keep hiding rules after refreshing or revisiting the page.
- See how many matching offers are hidden on the current page.
- Temporarily reveal hidden offers without deleting your rules.
- Search and restore hidden items from the extension popup.
- Import or export your rules as a JSON file.
- Choose English, Slovak, Polish, Czech, or Hungarian.

All rules and settings stay in Chrome's local extension storage on your device. The extension does not send browsing data to the developer, does not use analytics or advertising, and does not require an account.

Supported marketplaces: allegro.sk, allegro.pl, allegro.cz, and allegro.hu.

Offer Hider for Allegro is an independent extension and is not affiliated with, endorsed by, or sponsored by Allegro.
